# 插件中心（实施与验收范围）

## 已实施

侧栏「插件」是独立主内容页，分类为 MCP、Skills、扩展；安装包列在扩展分类并明确标记。复用现有主题变量、线性图标、细分隔列表，支持明暗主题和窄窗口。原对话保持挂载，返回不清空草稿。

配置范围选择全局或已知项目，不改变当前会话。扫描只读配置与资源文件，不执行扩展、不连接 MCP；项目是否加载仍由 Pi trust 决定。页面不替用户授权项目。

- MCP：单个服务新增（HTTP、本地程序/逐行参数、JSON）、启停、项目覆盖/恢复继承、移除；显式确认后执行独立 CLI 连接诊断；OAuth 登录使用系统浏览器。
- Skills：常规目录、兼容 `.agents/skills`、配置中的非通配本地路径扫描；简单 frontmatter 摘要与 Markdown 详情；本地目录接入、精确启停。不改写 SKILL.md 或删除源码。
- 扩展：常规入口、本地配置路径与内置项；精确启停。npm/Git/本地包交由 Pi 官方安装命令，确认前提示代码执行与脚本副作用；包更新/移除声明与资源启停区分。
- 保存：SHA-256 配置版本、与 Pi 相同命名的锁目录、原子替换、保留未知字段和权限；无任意 Shell/文件写入端口。MCP 凭据、原始 CLI 输出不回传前端。
- 应用：本页按已连接租约记录待应用会话，空闲时手动重新加载并刷新状态/命令；运行中按钮不可用，不中断任务。未连接实例下次启动读取。

## 当前明确未完成的原计划范围

以下不是已完成声明，也不应据此发布为完整插件管理：

1. Pi 1.4.0 公开扩展 API 的 `getMcpServers()` 只列扩展注册信息，不提供内置 MCP 连接管理器状态。尚未接入会话实时连接、工具枚举、逐工具 exposure、重连与详细脱敏诊断；独立 `pi mcp list --json` 的结果仅展示总检查状态，不冒充已有会话状态。
2. 没有修改现有 MCP 连接参数的编辑器、多项 mcpServers 导入、Codex TOML 导入及高级可见性编辑。
3. 静态扫描不完全等同于 Pi ResourceLoader：通配符、复杂 YAML、符号链接、包 manifest 内资源过滤/继承和包内资源清单尚不完整；不能完整管理包内单资源，不能提供可信的安装前完整清单。已有通配路径在 warnings 中提示，不改写它。
4. 插件操作任务及待应用租约目前属于页面状态；运行操作期间通过页内保护阻止导航，离开再进入不会保留应用状态。尚无工作区级持久化待应用版本、自动 idle 应用、安装取消与跨页面任务状态。
5. 尚无精确版本能力矩阵；原有命令入口已实测 Pi 1.4.0 CLI help，在线安装另在 Windows / Pi 1.5.2 验证隔离 npm 安装与 RPC 资源重载，其他版本不可视为已验证。项目安装/update/trust、真实 OAuth 和第三方来源安装没有三平台原生验收。
6. 安装与更新交给 Pi 自己持锁，本页不在外层持共享配置锁，避免死锁；安装过程中第三方脚本的外部副作用无法事务回滚。

## 在线搜索与全局安装

插件页标题区提供「在线安装」，在当前页面完成查找、选包、版本核对和安装。输入准确 npm 包名、`@组织/包名`、带精确版本/标签的包名或 `npm:` 来源均可查找；普通名称使用关键词搜索。无需输入 `npm`/`npx` 命令，页面也不运行第三方命令安装器。

- 查找并行进行准确查询和关键词搜索；准确命中置顶，候选只展示带 `pi-package` 标记的包，去重后最多 20 个。两路查询可部分成功并就地提示，不把模糊命中自动安装。
- 选包后核对包名、简介、发布者与精确版本，焦点进入安装详情。缺少 `pi-package` 和 `pi` manifest 的准确命中需用户确认适用于 Pi；标记和发布者信息不代表安全认证。
- 默认解析 npm `latest` 标签，用户指定精确版本或标签时按其解析；最终固定所展示的精确版本安装。不支持版本范围、历史版本选择器、私有源搜索或自动更新。
- 范围固定为 Pi 全局个人配置，不随列表的项目范围变化；项目已有配置会提示仍按 Pi 覆盖规则处理。已有全局同名包引导至安装包管理，避免重复安装。
- 安装复用官方 `pi install npm:包名@精确版本`，不传 `--local`。安装过程中保护导航、阻止重复提交。命令结束后读取全局配置核对，再报告已安装；刷新失败、超时或部分失败只提供重新读取，不自动重放安装。核对确认配置中没有该包后，可显式重新选择再手动安装，保留原搜索输入。
- 配置已确认后，所有已连接会话标记待应用；运行中不重载，空闲后手动应用，新连接读取配置。
- 查询后端固定访问公开 `registry.npmjs.org`，不读取 npm token、不跟随重定向，15 秒超时，搜索/元数据分别限制 1/5 MiB。实际安装沿用 Pi 的 npm 环境，源设置不同可能导致安装失败。

`npm install -g` 安装全局命令行工具，`npx` 运行包命令；两者本身不等于向 Pi 登记插件。本功能统一使用 Pi 包安装机制。

## 桌面视觉与选择器

采用克制的中性色表面、细边框和柔和绿色。列表工具栏仅在列表显示，详情/添加使用页内返回导航；扩展分类细分用户扩展、内置扩展和安装包。详情返回保留列表滚动位置，编辑与确认切换从页面顶部开始，不改变后台对话滚动。

配置范围和接入方式复用 `SettingsSelect`，统一 SVG 箭头、选中标记、说明和禁用态；项目超过五个时可按名称和路径搜索。浮层限定在页面滚动区内，空间不足向上展开，不参与布局。搜索保留空格及 Home/End 光标行为，方向键/Enter 选择，Escape 收起并返回入口；输入法组合期间不选择。非搜索入口保留原有 Home/End 导航。

添加分为填写来源和确认接入，按接入模式保留来源/参数草稿；单行地址与程序使用 input，仅 JSON 和逐行参数使用 textarea。预览是只读摘要，不回显 URL 认证/查询参数或原始 JSON；返回编辑才能核对原始值。保存不等于连接或会话加载成功。

操作错误与状态提示仅属于当前内容。确认切换分类、接入方式、详情或返回列表后清理上一项反馈；取消离开时保留原错误和草稿。导航使旧详情请求失效，迟到的失败不能重新显示错误或抢走新页面焦点；独立的待应用会话记录继续保留。

## 代码位置

- `src/lib/plugins.ts`：领域类型与专用 IPC 端口。
- `src/lib/components/PluginsPage.svelte`：管理页面、导航保护、操作预览及会话应用。
- `src/lib/components/PluginDetail.svelte`：统一元信息与按类型显示详情。
- `src-tauri/src/plugins.rs`：只读发现、版本、锁及配置补丁。
- `src-tauri/src/npm_registry.rs`：公开 npm 查询、来源解析、有界响应与元信息投影。
- `src/lib/components/PluginOnlineInstall.svelte`：在线候选、精确版本详情、全局安装与结果核对。
- `src-tauri/src/plugin_commands.rs`：官方 CLI 白名单调用、进程树和有界日志排空。

## 验证

新增 Vitest 组件测试、Rust 仓库/来源校验测试及 Playwright 明暗宽窄窗口测试；均由现有全量命令及 CI 自动发现。最终执行记录见 `docs/plugins-validation.md`。浏览器 IPC 替身不安装第三方包、不使用用户真实凭据、不调用在线生成模型。
