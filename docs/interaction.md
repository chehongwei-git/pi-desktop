# 交互

侧栏依次包含“置顶”“工作项目”“最近”，三块均可独立展开或收起。启动时自动发现 Pi 会话目录中的全部工作区，并补充最近打开的项目；“工作项目”默认展示前 5 个，可点击“显示全部”查看其余项目，收起区块后再次展开恢复前 5 个。工作区按会话 header.cwd 分组，按规范化路径固定排序，切换会话和刷新索引不会按活跃时间重排项目；点击项目展开或收起其中会话。“最近”跨项目展示会话，按最近更新时间排序，并标明所属项目。会话旁的图钉可置顶或取消置顶，偏好保存在本地配置中，重启后保留。

展开区块或项目不启动 Pi；点击会话才连接对应项目并恢复历史，项目旁的 + 可直接在该项目新建会话。搜索在所有项目的会话名称和首条用户摘要中匹配，自动展开匹配项目，搜索结果不受前 5 个项目限制。窗口重新获得焦点时刷新索引，设置中修改会话目录后立即刷新。打开历史后才能重命名，所有会话写入交给 Pi。会话名称固定显示在对话区顶部；切换时立即显示目标会话名称，正文区域仅显示加载转圈，覆盖跨项目连接与历史读取过程。加载完成后显示目标消息，期间禁用发送和重复切换；被扩展取消或切换失败时结束加载状态。

连接前输入禁用。点击“新对话”（或 Ctrl/Cmd+N）时，未选项目则直接在系统用户目录启动 Pi，已选项目则在当前项目新建会话。新对话在输入框上方显示文件夹按钮，展开后可搜索并选择全部已知项目，不受侧栏前 5 个项目限制；底部“新建项目”通过目录选择器指定工作目录，“不在此项目工作”切换到系统用户目录。展开和搜索不启动 Pi，切换工作目录保留当前草稿。菜单支持方向键、Escape、点击外部关闭。仍可通过目录选择器指定项目后连接 Pi。空会话使用居中欢迎页，出现消息后输入固定在底部。Enter 发送，Shift+Enter 换行，IME 确认不发送。提交失败保留原草稿，不隐式重发。草稿在内存按项目/会话保存，退出不长期保存。

运行时输入仍可编辑；发送须明确选择引导当前任务（steer）或完成后发送（followUp）。停止先清队列，再 abort；清出的文本列为可恢复草稿。5 秒未停止时显示强制关闭入口。运行中切换需选择停止并切换、等待完成或取消；等待可取消。

用户消息靠右，助手按正文排版；思考与工具默认折叠。普通消息直接显示正文，不出现重复的全文入口；只有正文超过 64KiB 预览上限时，才提供分块查看全文的入口。复制按钮复制当前显示文本。远程图片不自动请求，代码语言按需高亮。上滚立即停止自动跟随并取消待执行的底部定位；向下滚动到实际底部或点击回到底部才恢复跟随。加载历史保留滚动锚点。

快捷键：Ctrl/Cmd+N 新对话，Ctrl/Cmd+K 搜索，Ctrl/Cmd+B 侧栏，Ctrl/Cmd+, 设置。弹层使用原生 dialog 约束焦点，Escape 关闭并恢复焦点。扩展交互按队列显示，取消/超时最多回应一次。
