# 交互

## 每轮代码变更

输入框上方使用默认收起的 38px“代码变更”工具栏，以细分隔线、文件计数和增删统计组织信息，不使用厚重卡片。展开为 35px 单行文件清单，文件名突出、目录弱化、状态及统计右对齐，最多约五行并独立滚动；短窗口进一步限高。悬停、选中与键盘焦点分开反馈，选中状态跟随实际审阅文件，关闭后清除。点击文件后列表保持展开，收起列表不关闭详情；重新展开后关闭面板仍按稳定路径恢复文件入口，文件隐藏则返回工具栏。

轮次入口使用主题一致的小型就地菜单，限定左列宽度，支持方向键、Home/End、Enter 和 Escape，失焦或点击外部收起。采集说明通过信息入口按需展开，不常驻占用文件清单。查看历史轮次或文件后固定选择，不因新任务结束强制切换；切换轮次会关闭旧轮次差异，避免列表与内容错配。

会话顶栏下方由 ReviewLayout 组织左右两列：左侧保留对话、变更清单和输入区，右侧独立通高承载代码差异或长文本。展开清单、输入多行或附件增高不改变右侧边界。详情 DOM 保留原会话所有权，仅迁移至审阅宿主，缓存会话详情隐藏，不重建已读消息。右侧标题分文件名、目录与任务摘要两层，提供增删统计、复制路径和图标关闭入口。工作区实际宽度不足 820px 时进入页面内审阅模式，隐藏并 inert 保留对话与草稿，仅提供返回对话入口；变更工具栏、文件清单、轮次选择及采集说明始终只在左侧对话区，不在右侧复制。窄屏换文件须先返回原清单，保留展开状态、草稿和阅读位置；关闭恢复阅读位置和焦点。明暗主题复用已有变量。

宿主在提示词提交前采集工作区基线，在 agent_settled 后比较实际文件，不以 Git HEAD 为基线、不累加工具差异。统计包含采集范围内脚本或外部并发编辑，不承诺精确归因。单文件上限 1 MiB，总基线上限 16 MiB，条目上限一万个，排除 .git、node_modules、target、dist、build、.idea、.pi 和桌面辅助目录，不跟随符号链接。超限或不可读会显示范围说明，避免误报为新增或删除。比较时先剥离公共首尾，避免长文件的局部修改被误显示为整文件替换；剩余区域行数乘积超过一百万时使用该区域完整替换视图，并在差异顶部明确提示精度降级，增删统计对应该视图；二进制仅提示内容变化。最近十轮保存于会话根目录 .desktop-changes，按会话路径摘要隔离，每会话最多约 64 MiB。旧会话没有快照时仍从处理过程查看历史单次差异。新轮次结果不自动展开、不抢焦点。进程被强杀时无法保证最后一轮落盘。

## 视觉布局与阅读层次

主界面使用系统字体优先的跨平台回退，代码采用独立等宽字体回退；正文与输入为 16px，常用导航和控件为 13–14px，辅助说明约为 12px。中文欢迎标题不使用负字距。侧栏宽度为 288px，窄于 900px 时沿用可收起的抽屉；正文与输入共享 820px 最大内容宽度。

当前会话标题合并到顶栏，与连接状态及会话菜单同处一行，长标题省略并通过 title 保留完整名称。新会话与已有会话的输入器使用相同的底部位置，项目入口位于输入框上方。欢迎区在剩余空间内居中，短窗口仅欢迎区独立滚动。出现消息后沿用底部输入与独立正文滚动，不重新挂载对话。

浅色与深色主题分别定义页面、侧栏、输入表面、悬停和选中颜色。会话选中使用独立底色，键盘焦点使用轮廓；模型和强度入口减轻边框，保留文本、图标、启用色及键盘行为。折叠工具使用轻量摘要，展开后显示边界和吸顶标题；正文采用独立堆叠上下文，工具标题只在正文内部置顶，不遮挡输入区向上展开的模型、思考强度等菜单；失败仍突出错误状态。设置和归档沿用相同字号与表面层次，继续在主内容区完成。

视觉回归使用浏览器截图与现有任务测试，覆盖明暗主题、宽窄窗口、缩放、运行中输入、工具展开及长对话阅读锚点。浏览器验证不等于三个平台的原生客户端验证，也不代表已通过 WCAG 2.2 AA 审核。

## 长文本双路径

单次粘贴达到 1,000 个 Unicode 码点或 12 行时，在原光标位置收成两行卡片。卡片采用主题背景、12px 圆角和细边框，预览首个非空行并显示字数，默认 280px，窄窗口随可用宽度缩小。图片粘贴仍优先处理，菜单搜索不生成卡片。

**点击输入卡片还原文字**：点击或 Enter/Space 直接在原位置用完整原文替换卡片；卡片消失，前后文字保留，光标位于原文末尾，不操作系统剪贴板，不插入第二份文本。主输入区限高 200px、内部滚动，撤销可恢复卡片。还原后不再次自动折叠。

**普通文字发送后原地展开**：没有卡片记录的用户长消息（包括旧历史）达到 1,000 码点、12 行或被宿主截断时，默认显示最多 6 行、360 码点的纯文本预览。点击“展开更多”在该消息内读取并展开全文，顶部和底部均可收起；底部收起后焦点返回入口。助手及工具消息不适用此规则，短用户消息保持 Markdown 展示。

**保留卡片直接发送后右侧查看**：发送时未还原的片段在对话中保留为只读卡片，前后说明正常显示。点击卡片使用与代码变更相同的右侧区域；两种面板互斥，点击其他卡片切换内容。面板顶部显示字数、复制原文与关闭入口，正文使用纯文本及独立滚动。工作区实际宽度不足 820px 时在页面内审阅视图显示，保留隐藏对话 DOM；关闭或 Esc 恢复阅读位置及卡片焦点。展开/关闭只补偿本次布局变化，流式回答不能抢走阅读位置。

混合消息中各普通文字片段分别判断是否折叠，不把卡片隐藏进文字预览。两种路径都发送完整原文；“复制消息”读取并复制整条全文，“复制原文”只复制右侧卡片全文，预览不能冒充全文。分页失败保留已读内容并就地重试，关闭面板后丢弃迟到结果。读取按 64KiB 批量发布，避免每个小页都重排大段正文。

草稿继续保存有序片段。发送给宿主的可选 textParts 只包含 UTF-16 范围与身份，宿主验证后剥离展示字段再调用 Pi，不修改 Pi JSONL。展示 sidecar 位于现有桌面辅助数据目录，以规范会话身份、原始消息时间及正文/图片摘要生成键；有限元数据不重复保存全文。重启后校验摘要及范围才恢复卡片。重复候选、身份不足或存储损坏时安全回退为普通文字；缺少时间戳时仅当前运行保留卡片，并提示无法持久恢复。保存展示失败不自动重发消息。

保持两步删除、跨卡片复制剪切、中文组合输入保护、会话草稿恢复及发送失败保留。真实系统输入法、原生 WebView 和跨平台发布需要在对应系统额外验证，浏览器合成事件不替代原生验收。

## 上下文使用率

输入区右下角显示 Pi `get_session_stats` 返回的上下文使用百分比与已用／上限 tokens，数字缩写与终端一致；超过 70% 使用警告色，超过 90% 使用错误色，并提供对应的无障碍说明。压缩后未知用量显示问号，展开后说明需等待下一次回答。未连接、会话加载及本地新对话草稿页隐藏指标，避免展示后台旧会话读数。

点击指标在原处向上展开明细，展示累计输入、输出、缓存读取与写入、会话累计缓存命中率、费用及消息数；不打开弹窗。展开聚焦面板，Tab 可进入刷新按钮，Escape 收起并恢复入口焦点，点击外部或焦点移出时收起。连接、切换、任务结束及压缩后刷新，展开时也刷新；同一会话并发查询合并，迟到的旧会话结果忽略。查询失败保留上次读数，不打断消息发送。明细支持就地刷新。

## 消息提示

对话页反馈复用现有 68px 顶栏，短提示在连接状态旁显示图标、单行摘要、数量和关闭按钮。窄窗口仅保留图标和数量，完整消息仍可由辅助技术读取。点击“查看消息提示”后，详情替换顶栏标题与菜单区域，保持原有高度，长消息、多条提示及相关操作在该区域独立滚动；返回或 Escape 恢复入口焦点。正文、输入框和阅读位置始终不因反馈增减或详情切换而移动，也不额外补偿滚动。不打开弹窗。归档及设置页继续沿用页内反馈区域。

错误优先于停止警告及普通反馈，其他提示通过“还有 N 条提示”就地展开。普通反馈默认 3 秒收起，下一次有效提交时提前清除；错误及历史反馈默认 8 秒收起。查看详情、悬停、键盘操作以及隐藏的低优先级消息暂停计时。停止警告和压缩状态保持至关闭或业务更新，不被普通发送反馈覆盖。模式标记独立显示，关闭反馈不改变计划模式。重连、设置、撤销及强制关闭操作保留在对应详情内。

反馈到达不抢焦点；错误通过 alert，普通消息通过 status 播报。保留明暗主题及减少动画偏好支持。浏览器回归验证提示出现、消失和详情切换前后正文及输入框的几何位置完全一致，覆盖首条消息、阅读锚点、错误优先、多条提示、窄窗口和高缩放。浏览器验证不代表已完成 Windows、macOS、Linux 原生客户端验证。

## 应用设置

侧栏“设置”与 Ctrl/Cmd+, 在主内容区打开同一个设置页，保留已挂载的对话、草稿和阅读位置。页面分为“外观”“Pi 连接”“模型与服务商”“会话与存储”，切换分类保留未保存的输入。外观使用带预览的原生单选卡片选择跟随系统、浅色或深色，保存后应用；缩放显示当前比例并提示 Ctrl/Cmd 与 +、−、0 快捷键。

Pi 连接集中展示入口、运行时和额外 PATH，提供可选标记、默认行为说明和独立的路径浏览入口。“检测 Pi”使用当前表单配置，在页面内显示版本、路径或失败详情。会话目录说明默认位置与保存后的索引刷新；兼容性说明按需展开。

底部固定显示保存状态与保存入口，提交时禁用重复操作，保存失败保留全部输入并可重试。侧栏归档、设置及对话导航以当前可见页面为准，归档与设置不会同时选中。设置中可直接点击归档、新对话或历史会话切换，无需先返回对话；存在未保存更改时，侧栏设置项显示“未保存更改”，分类导航以圆点标记改动，底部显示改动分类。返回、Escape 与侧栏导航统一展开底部警示条，通过警示底色、图标和标题说明状态，显示将前往的会话或页面，提供“继续编辑”“放弃更改并继续”与主操作“保存并继续”（返回时为“保存并返回”），不打开确认弹窗。确认条聚焦主操作，取消或 Escape 恢复触发控件焦点；保存失败保留草稿和目的地，在确认条就地提示并允许重试。提交期间的导航显示处理状态并记录最新目的地，禁用重复提交，保存成功后继续前往目标；检测或读取结束仍有草稿时等待用户选择。保存成功更新草稿基线，已保存内容不再标记未保存。进入设置聚焦标题，返回恢复触发控件焦点。窄窗口中分类导航变为横向，内容区独立滚动。保存成功统一提示“设置已保存”；启动路径和环境配置用于下次启动 Pi 的说明仅在“Pi 连接”分类展示。模型与 API Key 可在“模型与服务商”中配置，OAuth 登录仍由 Pi CLI 管理。

## 模型与服务商

模型设置与本机 Pi CLI 共享 agent 目录中的 models.json、auth.json 和 settings.json，遵循 PI_CODING_AGENT_DIR；页面展示实际目录。认证只返回来源和已配置状态，不显示原始凭据。认证方式目前只有 API Key，输入新密钥表示替换，留空保留已有认证；环境变量、免认证和订阅不提供新增选项，后续扩展订阅时再增加认证方式。替换 OAuth 需就地确认；已有命令型密钥与高级请求头原样保留，模型发现不执行密钥命令。

页面参考 @rotriz/pi-web-ui 1.6.0 的可搜索模型列表组织方式，使用自定义端点列表与详情区；窄窗口上下排列。只管理显式 API 地址的自定义端点，内置服务商及已有模型覆盖保留但不提供编辑入口。端点列表支持名称和地址搜索，添加在列表内展开，使用独立标识、必填完整 API 地址和明确协议，不再提供继承内置服务商入口。创建端点时显示名称默认填入端点标识，之后可独立修改。认证和 API Key 输入直接展示，全局默认值与共享配置说明按需展开。获取模型使用当前未保存的 API 地址、协议和认证，支持 OpenAI Chat Completions、Responses 及 Anthropic Messages。基础地址保留路径前缀，请求其下的 /models；需显式填写地址和协议才能发现模型。列表支持搜索、选择搜索结果和分批显示，勾选后加入草稿；失败不清空表单，可手动添加。取消等待会忽略迟到结果，宿主请求最多持续 30 秒。再次拉取不覆盖已配置参数；未返回的已有模型仅标记，不自动移除。模型目录可访问不代表生成请求或工具调用可用。

每个模型就地展开名称、上下文长度、最大输出、图片输入、思考能力。手动新增和远端发现的模型默认强度为 off、reasoning=false；选择具体强度后才设为 reasoning=true 并应用对应等级。不再提供独立的思考能力下拉框；最终生效等级为 off 时关闭思考，其他等级开启，并在等级控件旁以文字说明状态。跟随全局时使用全局等级，未配置全局时为 off。读取及保存自定义模型时均按最终强度归一化能力，旧配置中的冲突值在保存后修正。旧自定义配置缺少 input 时保持字段缺省，设置页按 Pi 实际解析的模型能力显示“未配置（当前仅文字／当前文字与图片）”；目录尚未就绪时显示“未配置（由 Pi 决定）”。读取、展示、连接与刷新不补写或覆盖 Pi 的图片能力，保存其他字段也不自动新增 input。用户明确更改图片选项并保存后才写入或移除该字段。手动新增和远端发现的模型仍在新建草稿中显式设置 text/image。保存后同步未连接草稿的已声明能力；缺省时保留 Pi 已确认值，刷新后以实际目录为准；已有会话配置尚未应用时，图片发送就地提示待应用或应用失败并保留文字与附件。其他能力留空或“继承默认”不写入覆盖，关闭图片或思考保存显式值。页面新增模型统一使用 models；已有 modelOverrides 原样保留，不在此页面展示或新增。数值必须为正整数且最大输出不能大于显式上下文长度。远端缺少图片能力数据时默认支持图片，上下文或输出数据缺失时继承 Pi 默认；当前界面不展示目录继承参数的有效数值。

API 协议、图片输入、全局与模型默认思考等级使用统一的页面内选择器，统一边框、圆角、焦点、选中标记与明暗主题。选项以固定定位浮层贴近入口展开，不占页面布局高度，不推移下方组件或改变设置页滚动范围；优先向下，底部空间不足时向上，边界限定在设置内容可见区，避开页头和保存栏。列表限定高度并独立滚动，键盘浏览只调整列表内部位置；页面滚动、窗口尺寸与缩放变化时同步定位，入口离开可见区域后收起，关闭时释放监听。长选项换行。思考等级同时显示中文含义与原始标识，继承项说明全局生效等级。方向键与 Home/End 浏览，Enter/Space 确认，Escape 收起并保留入口焦点，Tab、点击外部及窗口失焦收起；保存期间跟随表单禁用。

思考映射支持 off/minimal/low/medium/high/xhigh/max，每项可继承、禁用（null）或填写服务端值。所有等级默认可选，xhigh、max 缺省时由桌面桥接补齐同名映射，已有服务商映射及显式禁用保留；保存自定义模型的扩展默认等级时补齐对应映射，避免 Pi 启动时降级。映射位于默认等级之后的高级折叠面板，关闭思考时也可编辑；收起时显示调整项数。展开后按等级、支持方式和服务端值对齐，使用统一页面内选择器；窄面板按实际宽度换行，空服务端值就地提示。实际支持范围仍由服务商决定。配置模型默认等级与全局默认等级，新会话默认模型与当前会话选择分开；当前会话使用输入框底部的模型和思考控件。全局默认思考等级未配置时默认为 off。默认模型列表只列出自定义端点中的模型，既有 CLI 默认值仍保留并标明已有配置。

保存沿用设置页底部入口，模型草稿在切换分类时保留。成功清空新输入密钥并继续停留页面。空闲时仅刷新本地模型配置并重新应用当前模型；运行中保存并延后至 idle。失败明确区分保存失败与已保存但应用失败，可重试应用。默认启动设置需要后续新进程读取，必要时重新连接；共享默认值不强制覆盖项目选择；项目默认模型只用于后续新会话，恢复历史保留会话自身选择。未连接时保存不启动 Pi。移除模型和服务商配置均就地确认；服务商移除可选清除凭据，保存前可撤销。保留的认证独立存放于 auth.json，后续保存不会因此在 models.json 中重建空服务商；保存时会清理旧版本遗留的空服务商对象。

外部修改触发版本冲突，保留草稿；重新读取需就地确认放弃草稿。共享配置损坏时不覆盖，需先修复文件。每个文件原子替换，多文件 IO 失败尝试逆序恢复；进程在保存期间被强杀仍可能留下部分写入及锁目录，需要检查共享配置。与 CLI 共用目录锁，不主动抢占锁。

## 侧栏操作与布局

项目和会话提供“更多操作”按钮，与右键共用重命名、归档菜单。菜单支持方向键、Home/End、Enter 和 Escape；主动关闭时恢复入口焦点，点击外部或窗口失焦时不抢焦点。重命名在原行内完成，Enter 保存、Escape 取消，输入法确认不提交；保存失败保留输入并就地显示可重试错误。结束编辑后恢复原对象焦点。归档保持原有撤销与恢复流程。

最近会话和每个项目的会话默认显示 20 条，可按每次 20 条继续加载，计数徽标仍显示完整数量。已归档与设置固定在侧栏底部，不随历史列表滚动。区块和项目展开状态、侧栏显示状态保存在当前应用的本地界面偏好中；存储不可用时使用页内提示。搜索临时展开不写入普通浏览偏好。

会话采用整行悬停与焦点反馈，已置顶图钉持续突出；鼠标环境下次要按钮弱化，但位置始终保留，键盘聚焦和触控环境正常显示。当前项目通过底色、文字及侧边标记共同表达。打开侧栏聚焦搜索入口，收起后返回展开按钮；Escape 优先清除搜索，窄窗口无搜索时收起侧栏。取消置顶导致当前行消失时，焦点移到相邻会话或区块标题。

## 跨项目并行任务

跨项目任务直接融入“置顶／工作项目／最近”列表，不提供独立“进行中”面板。列表将 Pi 历史与本机草稿、排队及恢复条目合并；从本地恢复的条目不显示“待恢复”标识，未发送的新会话内容沿用“草稿”状态，草稿恢复与中断提示保持可用；真实文件出现后沿用原桌面身份并按路径别名去重，不为本地条目伪造文件路径。名称旁使用固定尺寸的语义状态图标：运行中为低调旋转环，完成为勾选圆环，失败为警示圆环；排队、待你处理、停止、中断和草稿也使用相同图标槽位，悬停标题及无障碍名称提供文字状态。减少动画偏好下运行图标静止。状态更新不重排列表、不增加常驻第二行、不切换会话或抢焦点；后台完成产生独立未读点，打开后清除未读但保留完成图标。可恢复的活动在归档会话或归档项目下暂时显示“已归档”，活动及待处理扩展结束后依归档规则隐藏。

默认同时执行 4 个会话，设置的“会话与存储”可改为 1–16，所有项目合计共用名额。新草稿首次发送进入全局队列。发送前与排队中的无文件会话均显示在对应项目及“最近”中；本地草稿点击后原地恢复编辑而不启动 Pi，已有活动实例点击后复用，历史实例按需恢复。名称和摘要纳入全局搜索及原有分页，按最近发送时间、创建时间排序，状态变化不重排。未落盘的本地项不提供依赖真实文件路径的置顶或归档操作。每会话独立的停止入口仍位于当前输入框区域。排队任务保留提交时的模型、强度和附件快照，后续草稿不会改变它；取消后就地恢复输入而不自动发送。

切换保留各会话消息、工具展开、草稿和阅读位置；跨项目缓存最近十二个已加载会话的内容、最近六个对话视图，两层分别按最近访问顺序淘汰；空白本地草稿不占内容额度。默认全局保留最多 5 个空闲 Pi 进程，按需增长、无固定超时；“会话与存储”可调整到 0–20，0 表示不缓存后台进程。运行任务另计，缓存会持续占用内存。超额按最近访问顺序复用或回收后台进程，不清空正文或移除缓存视图；运行、排队、提交、连接恢复、历史加载及等待扩展交互期间不回收。切回已有健康连接的会话直接展示，不显示恢复连接；没有连接时先展示已有内容再获取进程。慢操作延迟 200ms 显示“正在连接”“正在加载会话”或“正在创建会话”，故障重试使用“正在恢复连接”，不遮挡正文、不重置阅读位置，草稿仍可编辑。发送等待连接完成且仅提交一次，失败保留输入；连接失败提供就地重试。尚未加载的正文、工具详情及图片等待新引用恢复，隐藏视图不自行启动进程。超过内容额度时释放最旧且未挂载、未受运行保护的正文，保留草稿、展开偏好和阅读恢复信息。正文仍受现有预算约束，缓存数量不等于永久保留全部历史。关闭应用时页内确认停止所有项目的任务，Escape 或“继续工作”取消；退出等待超过 5 秒提供强制停止。重启将原任务标为中断或未执行，只恢复文字供手动编辑和提交，不自动续跑，图片需重新添加。

## 归档管理

归档是唯一的历史收纳入口，不再提供回收站或移入回收站操作。旧版 deleted 记录在归档中兼容展示，下次成功保存归档元数据时统一为 archived；恢复和撤销均保留原始文件。

侧栏“已归档”在主内容区打开管理视图，不使用模态弹窗。进入时保留已挂载的对话、草稿和阅读位置，返回对话不重新加载历史。归档按“全部／项目／会话”分类并显示数量，按所属项目分组，支持项目筛选与名称、项目名、路径组合搜索。无法从索引确定项目的旧会话归入“未识别项目”。首次显示 50 项，可继续加载；筛选后重置展示数量，区分空列表与无匹配结果。

归档直接执行并提供最近一步的撤销；恢复也支持撤销。保存失败保留原状态并允许重试。归档当前会话不会中断任务或清空草稿。归档项目一并隐藏其会话，但不改变单个会话的状态；恢复项目不会恢复单独归档的会话。恢复会话时如所属项目仍归档，则提示需恢复项目。

进入管理页聚焦标题，恢复一项后聚焦相邻恢复按钮，列表为空时回到标题，返回时恢复入口焦点。

侧栏依次包含“置顶”“工作项目”“最近”，三块均可独立展开或收起。启动时自动发现 Pi 会话目录中的全部工作区，并补充最近打开的项目；“工作项目”默认展示前 5 个，可点击“显示全部”查看其余项目，收起区块后再次展开恢复前 5 个。工作区按会话 header.cwd 分组，默认按规范化路径排序；可拖拽项目标题调整顺序，落点显示上方或下方插入线，也可聚焦标题后使用 Alt+↑/↓。项目顺序保存到配置中，重启、搜索、切换会话和刷新索引都不会按活跃时间重排项目。点击项目展开或收起其中会话；项目内会话和“最近”都按最后发送用户消息的时间倒序排列，发送成功后立即提前；打开、重命名、助手回复或文件更新时间变化均不改变顺序。没有用户消息时以创建时间和路径作为稳定排序依据。“最近”跨项目展示会话，并标明所属项目。会话旁的图钉可置顶或取消置顶，偏好保存在本地配置中，重启后保留。侧栏历史列表为滚动条预留稳定间距，置顶按钮与滚动条之间保持可点击的安全距离。区块标题使用舒展的行高与分组间距，统计数字以浅色徽标紧随标题，右侧操作按钮独立留白；项目行统一箭头尺寸、行高和计数徽标，长项目名省略显示，计数与新建按钮之间保留间距。

应用启动时在最近项目（没有则使用系统用户目录）预先连接一个 Pi 实例；展开区块或项目不创建额外进程。正在执行的会话独占 Pi，跨项目及同项目均可并行；空闲进程可被其他会话借用，旧会话保留页面及草稿缓存；点击历史会话只切换当前查看对象，后台任务继续。相同会话重复打开复用已有实例。项目旁的 + 准备对应项目本地草稿，首次发送进入全局队列，获得名额后优先借用同项目空闲实例调用 new_session，没有合格候选再启动实例。搜索在所有项目的会话名称、首条用户摘要、项目显示名称和工作目录中匹配，自动展开匹配项目，搜索结果不受前 5 个项目限制。搜索框提供清除入口与会话结果数量；没有结果的区块隐藏，全部无匹配时统一显示一条说明。搜索期间可独立折叠区块和项目，清空搜索后恢复原浏览布局。窗口重新获得焦点时刷新索引，设置中修改会话目录后立即刷新。侧栏重命名统一修改桌面显示别名，不修改会话文件或工作目录；顶部会话菜单的重命名仍交给 Pi。会话名称固定显示在对话顶栏；切换时立即显示目标会话名称，正文区域仅显示加载转圈，覆盖跨项目连接与历史读取过程。加载完成后显示目标消息，目标加载期间禁用发送，仍可选择其他会话；被扩展取消或切换失败时结束加载状态。

Plan 扩展的 plan-todos 在输入区上方显示为“执行计划”紧凑卡片，包含已完成数量、进度条与首个未完成步骤；默认收起完整列表，可通过“展开全部／收起步骤”就地切换。完整列表使用只读状态图标、序号与步骤正文，首个未完成项突出，完成项弱化并加删除线；长内容换行，列表限定高度并支持键盘滚动，Escape 收起并恢复展开按钮焦点。进度更新保留展开状态，不抢焦点；全部完成显示明确提示。未知非空行保留为未完成步骤，不静默丢弃扩展内容。Plan 扩展发出的 `ℹ ` 行单独展示执行状态和阻塞原因，不计入步骤总数。运行中显示“正在执行”，空闲且扩展提供 todos 命令时提供“继续执行／停止计划”；操作直接发送扩展命令，保留输入草稿和图片，防止重复提交，失败在卡片旁提示。运行中停止复用现有停止任务流程。

Plan 完成工具 `plan_mode_complete` 作为面向用户的交付内容独立显示在对话正文中，不并入默认收起的处理过程。最终计划从调用参数的 `plan` 字段分块读取，默认完整展示 Markdown 并复用消息复制功能；原始工具状态和详情保留在下方按需展开。读取失败就地提示并可重试，缺少参数时提供原始详情入口；切换会话或正文引用后忽略迟到结果。运行中及提交失败分别明确标注，不把参数中的方案误报为成功提交。普通助手回复保持原有展示路径，该兼容展示不按操作系统区分。

计划能力由用户自行管理的 Pi 扩展提供，桌面不附带配套 Plan 扩展，不安装、复制、更新或覆盖用户扩展文件，也不修改 Pi 安装源码。已有扩展通过官方事件提供进度时，继续展示计划卡片；只有 Pi 命令目录包含 todos 时才提供继续／停止入口。自动续跑、步骤完成判定和恢复规则由实际加载的扩展决定，桌面不承诺特定扩展实现。前端按事件顺序在 reset 清除旧扩展状态，保留同批 reset 后的新状态。

新对话尚未首次发送时只是本地草稿页，后台保留原会话。原会话的扩展状态和 Plan 待办组件在新对话草稿页及会话加载期间隐藏，返回原会话后恢复展示，不因准备草稿清空原会话数据。在草稿页显式选择的模型会在首次发送创建真实会话后再次应用，避免创建时恢复默认模型导致选择失效；模型应用失败保留首条消息并停止发送，重试不重复创建会话。此时点击后台仍在使用的会话，直接返回其正文并恢复原草稿，保留工具展开状态；新对话未发送的草稿独立保存，再次进入时恢复。首次发送创建真实会话成功后，消费该项目的本地新对话草稿；发送成功后再次新建输入为空。发送失败时文本归属已创建的会话并保留供编辑和重试，不重复创建；创建失败或被扩展取消时仍保留本地新对话草稿。返回原会话时，若租约仍有效则不触发 Pi 会话切换或扩展钩子；若进程已借给其他会话则按历史恢复流程重新获取租约；点击其他历史会话仍按正常恢复流程处理。

新草稿可以在尚未连接时编辑。同项目新草稿继承来源会话已发现的命令列表，第一条消息发送前输入 `/plan` 即可补全；跨项目仅复用目标项目已连接会话的命令，不借用其他项目的扩展或提示词。没有可用命令元数据时保留内置提示，连接后按运行时实际命令列表刷新。显示补全不提前启动进程。宿主确认首次提交已接受后，当前对话立即显示已提交的用户文字和图片，不等待 Pi 进程初始化或模型首个输出；此展示只保存在本机界面，Pi 权威用户消息到达后替换且不重复显示。提交失败保留草稿，取消或启动失败清理本地展示并沿用任务输入恢复流程。点击“新对话”（或 Ctrl/Cmd+N）准备本地草稿，未选项目则使用系统用户目录，已选项目则使用当前项目；首次发送获得名额后才启动 Pi。新对话在输入框上方显示文件夹按钮，展开后可搜索并选择全部已知项目，不受侧栏前 5 个项目限制；底部“新建项目”通过目录选择器指定工作目录，“不在此项目工作”切换到系统用户目录。展开和搜索不启动 Pi，切换工作目录保留当前草稿。项目选择面板使用标题与说明、名称/路径搜索、带数量的项目列表及独立底部操作区。项目名称与完整路径分两行显示，当前项目通过底色、“当前”文字及勾选共同标记；用户目录选项也显示选中状态。无项目与搜索无结果分别提供就地说明，列表独立滚动，适配明暗主题与窄窗口。项目面板在按钮上方向上展开，不参与页面排版，展开与收起均保持输入框位置不变；欢迎区独立滚动，避免裁切项目面板。打开后聚焦搜索；方向键在搜索、项目和底部操作间移动，搜索框 Enter 选择首个匹配项目（IME 确认除外），按钮 Enter/Space 执行，Escape 收起并恢复入口焦点，Tab 移出或点击外部关闭。鼠标按下菜单按钮时显式将焦点移到按钮，避免 macOS WebView 在 click 前因搜索框失焦而提前卸载面板。选择当前项目只收起面板，不重复连接。仍可通过目录选择器指定项目后连接 Pi。空会话使用居中欢迎区，输入框始终保持在底部。Enter 发送，Shift+Enter 换行，IME 确认不发送。提交失败保留原草稿，不隐式重发。文字草稿按项目/会话在本机保存，重启后恢复；图片仅保存在内存。

输入区通过附件图标“添加文件”、系统文件拖入及截图粘贴准备草稿，用户仍需主动发送。PNG、JPEG、WebP、GIF 作为图片发送；其他文件及目录作为完整绝对路径引用，目录不递归展开。BMP、TIFF、HEIC、AVIF、SVG 等图片格式明确标注“此格式按路径引用”，本次不进行转换。普通文件不自动读取或上传全文，Pi 按需通过工具读取路径。图片沿用单条最多 8 张、单张最多 10 MiB、总计最多 24 MiB 的限制，包含已有附件；普通引用不计入图片大小预算。

所有附件在正文输入区上方按添加顺序单行排列，无附件时隐藏。图片采用 80px 缩略图，文件采用 200×80px 紧凑卡片，窄窗口可缩小，多个附件横向滚动。统一 12px 圆角、细边框和主题变量；文件名突出显示并保留扩展名，目录和引用类型采用次级文字。移除按钮常驻且具有至少 24px 点击目标。点击图片原地预览，点击文件展开完整路径、复制和行内编辑；同时只展开一个详情，不增加应用弹窗。路径编辑验证当前平台的绝对路径语法，Enter 保存、Esc 取消，Shift+Enter 可保留 POSIX 文件名中的换行；修改后的路径仍为引用，不自动转换成图片。收起详情返回原卡片，移除后聚焦相邻附件或正文。

拖入时仅在输入框内高亮并覆盖提示“松开以添加文件”，不改变输入和按钮的几何位置。桌面使用 Tauri 原生事件取得真实路径，转换物理坐标后只路由至当前可见且可编辑的输入框。原生拖入由绑定窗口的一次性票据授权读取；图片签名与预算在宿主校验，普通文件不读取全文。连续导入逐批归并，失败项就地说明，成功项保留；读取期间暂停发送，切换上下文或卸载后忽略迟到结果。浏览器开发环境保留图片输入，普通文件缺少真实路径时明确提示使用桌面端或手动输入完整路径，不以文件名或 fakepath 冒充。Windows 启用原生拖放后，侧栏排序和编辑器内部选中文字的拖动使用 Pointer Events。项目保留 Alt+↑/↓，文字和长粘贴卡片可移动、取消、撤销，并按平台习惯用 Ctrl／Option 拖动复制；完整卡片移动保留身份，复制分配新身份。三个平台的系统拖入、DPI/多屏和原生编辑行为仍需原生验收。

附件、正文和长文本片段按项目／会话共同保存为快照。新会话、普通发送、引导及后续消息共用组装规则：正文保持原样，路径在末尾“文件引用：”区块逐行用 JSON 字符串表达，图片沿用原来的图片协议。仅附件也可发送；附件与斜杠命令同时存在时保留草稿并提示。模型明确不支持图片时提示切换模型，普通路径引用仍可发送。提交失败保留全部草稿，不隐式重发；成功只清除本次提交的实例，发送期间新增或编辑的引用保留。排队取消和停止从本地完整快照恢复，通过“恢复附件消息”找回并交换保留当前草稿。

恢复存储结构升级至 v2，兼容 v1。文字、片段与路径引用可在重启后恢复，图片数据仅保留在内存，重启提示重新添加；恢复不会启动任务或打开文件。路径移动或失效时仍保留供编辑。发送后的引用在正文下显示只读卡片，可就地展开完整路径、复制或切换查看原文；复制消息保持实际发送正文。旧历史仅在末尾严格匹配标准引用区块时转换，不确定时保留原文，不修改 Pi JSONL。图片预览及历史读取沿用受控引用，解码失败就地显示占位和恢复操作，不加载远程图片。

输入框为空时，按 ↑ 召回当前会话最近发送的提示词，连续按 ↑ 翻阅更早记录；按 ↓ 返回较新记录，越过最新一条恢复空输入，到最早一条不循环。召回后光标位于首部（向上）或尾部（向下），多行内部保留原生光标移动，仅首行 ↑、末行 ↓ 切换历史。修改召回内容后退出翻阅，非空普通草稿不会被覆盖。输入法选词、修饰键和选区操作不触发召回；命令菜单优先使用方向键，召回的斜杠文本不会自动打开菜单。提示词按消息 ID 区分，保留重复文本，包含已确认排队的引导与后续消息，排除提交中的占位和失败提交。更早页面与长正文按需读取，独立于对话列表，不改变阅读位置；读取时就地显示状态，失败保留内容，可再次按方向键重试。输入或切换上下文使迟到读取失效，新对话草稿页不使用后台会话历史。发送后的修改文本作为新消息提交，不改写历史。

模型和思考强度位于输入框底部左侧，以图标、文字和强度启用色区分，发送按钮位于右侧。模型和思考强度按会话独立，通过下拉控件或 /model、/thinking 修改只影响当前会话。已有项目模型偏好仅在没有来源会话模型时作为新会话初始值；点击新会话（包括跨项目和复用未发送草稿）始终继承来源会话当前模型及思考强度，保留目标草稿文字和附件，不改写项目偏好。普通侧栏切回草稿保留其手动选择。桌面端不再提供输入框上方“设为项目新会话的默认模型与强度”快捷设置；已有会话始终按自身配置恢复。模型使用输入区内向上展开的搜索面板，按服务商分组，服务商及组内模型按名称排序，保留当前会话中未在目录返回的模型；模型名称与 ID 分行显示，当前项通过底色、文字和勾选标记。入口同时显示模型名称和服务商。搜索匹配名称、ID 与服务商；初次展示最多 80 项，可继续加载，分组数量表示已展示项数。打开聚焦搜索，方向键在搜索及选项之间移动，按钮支持 Home/End，搜索框 Enter 选择首个结果（IME 确认除外），Escape 关闭并恢复入口焦点，Tab 移出或点击外部关闭。切换模型后重新应用当前思考强度；若新模型不支持原等级，则显示就地通知并采用 Pi 返回的有效等级，强度恢复请求失败时明确提示模型已切换并保留草稿。草稿页首次发送重建会话后也保留所选模型及思考强度。思考强度使用输入区内向上展开的菜单，显示中文等级、原始等级标识、用途说明及当前选中标记；入口以阶梯图形和文字表达当前强度。Enter/Space 或方向键打开，方向键与 Home/End 移动，Enter/Space 选择，Escape 关闭并恢复入口焦点，Tab 移出、点击外部或窗口失焦时关闭且不抢焦点；仅展示当前模型支持的等级。模型或强度切换期间暂停发送和重复切换，保留可编辑草稿；失败在控件附近提示并恢复 Pi 确认的选项。运行中允许选择模型与思考强度，但仅暂存到当前会话，控件立即显示新选择并注明“下次发送时应用”。当前任务、工具续答以及任务结束后均不自动切换；只有用户下次主动发送有效消息时才先应用暂存配置，再提交消息，切换失败保留草稿、附件与暂存选择，不自动重发。模型与强度通过同一桥接命令应用，加载、提交、停止或已有切换请求尚未完成时防止重复操作；排队任务保留提交快照。新草稿的选择立即更新控件，无需发送消息。窄窗口控件与发送区换行，适配明暗主题。

运行时输入仍可编辑；响应失败且自动重试后仍失败时，仅显示最终失败提示，不将已提交的消息列为未发送消息，也不新增“恢复未发送消息”按钮。Enter 或“发送引导”直接提交 steer，在下一个可处理节点生效；“完成后发送”提交 followUp，排在当前任务之后。发送与“停止任务”是独立按钮，停止按钮使用实色圆形背景；提交中避免重复发送但仍可停止。引导与后续消息提交时立即显示在对话中，标明正在提交/等待处理，Pi 返回正式用户消息时原位替换，避免重复。提交成功反馈提示，失败移除占位并保留草稿。停止先清队列，再 abort；清出的文本列为可恢复草稿。5 秒未停止时显示强制关闭入口。右上角会话菜单不提供普通“断开 Pi”操作；底层关闭能力仍用于停止超时后的强制关闭及显式 /quit 命令。运行中可直接切换到其他项目、会话或管理页面，原任务继续；停止只影响指定会话。

用户消息靠右，助手的所有普通文字（包括中间说明与最终回答）正常展示，收到正文增量即流式显示。同一助手消息包含正文、思考及工具调用时按内容拆分，正文不因 toolUse 或旧 presentation 分类而隐藏。每两次普通回复之间连续的工具调用、结果与思考统一归入默认收起的“处理过程”；思考位于同条消息正文之前，后续工具位于正文之后。空助手占位和已加载完整正文仅含空白的助手消息不创建可见分界，即使带有正文引用也合并前后过程；空预览引用仍保留加载入口，截断预览不以局部空白推断全文。直接回答且无过程内容时省略入口。入口显示运行／完成／停止／未完成状态、工具调用次数（无工具时省略）及本组耗时，不显示“有步骤失败”等单次工具失败汇总；工具自身的执行状态与错误详情在展开后保留，单次工具失败不令整组变成失败。需要用户操作的扩展请求继续在输入区上方可见。

分组以可见正文为边界，不推测自然语言是否属于最终回答。首组从 agent_start 开始，普通正文首次出现时冻结此前过程，包含思考和等待；正文结束后的工具创建新的独立计时，下次助手消息的思考继续归入该组，直到新正文开始。非流式消息在消息结束时冻结。并行调用按实际经过时间计算，不累加工具时长；自动重试期间继续计时，任务停止或失败时冻结。选择、确认、输入和编辑类扩展请求等待回答期间暂停计时，收起操作区不恢复；回答、取消或超时响应成功写入 Pi 后恢复，发送失败保持暂停。多个待回答请求全部响应后才恢复，重叠等待只扣除一次；状态通知和普通提示不暂停。暂停起点及累计等待时长沿用现有元数据保存，旧记录按无暂停处理。入口每秒更新一次且不逐秒播报，按秒、分秒、小时分钟显示。过程入口统一采用无强调背景、无运行动画的轻量文字样式，显示“处理过程”、工具次数与本组耗时；运行时计时文字为“已用时”，停止和未完成仍明确标注。输入框上方不再显示运行状态条；唯一主要运行提示放在当前对话末尾，与助手正文左对齐，使用三个 4px 圆点柔和交替明暗及简短状态文字，无边框、无背景、不上下跳动。等待首次输出、思考和工具执行时显示对应阶段，并行工具显示进行中数量；正文流式输出时隐藏圆点，由正文光标接续。重试、压缩、停止使用明确文案，等待用户操作时圆点静止；任务结束后移除提示，不写入历史。工具行仅保留静态状态点和执行状态文字。主提示不重复展示耗时或完整命令，阶段变化不抢焦点，状态容器保持挂载；提示属于对话滚动内容，沿用底部跟随，上翻不强制滚回，可通过“回到底部”返回。新对话草稿页与会话加载期间隐藏后台旧会话活动。停止按钮仍在输入框内。减少动画偏好下圆点保持静态；明暗主题共用语义颜色变量，不依赖动画或颜色单独传达状态。阶段通过 status 播报，不逐秒播报计时。

计时元数据由宿主保存在会话根目录的 .desktop-process 子目录，每条助手消息及工具结果以原始数字时间戳和正文摘要生成 v2 文件名，不写入原始提示词，也不改写 Pi JSONL。消息结束写入，普通正文开始及任务结束同步对应组的最终时间；恢复历史时读取同版本记录。旧版整轮计时不套用到新的分组，缺少数字时间戳或新版元数据时不显示耗时。写入失败记诊断，当前会话仍可查看，但重启后可能没有耗时。未正常结束的进程中断仅恢复最近已保存的状态，不推算离线时长。

展开状态沿用会话内界面状态，不因执行更新或任务结束自动改变；首次恢复历史默认收起。折叠区详情按需挂载，不主动读取完整工具输出；关闭后保留已有正文缓存。底部“收起处理过程”及详情内 Escape 收起并恢复入口焦点，工具变更仍在当前对话内展示。分组使用宿主稳定标识，历史补载合并同组；引导消息保持可见，尚未处理的排队消息不切断当前组。展开／收起停止底部跟随，用户阅读时不持续补偿滚动。

过程区内工具步骤显示工具名、完整命令或文件路径及状态，命令自动换行。输出、参数、详细错误、截断说明与完整输出路径默认隐藏，不展示任何正文预览。点击标题“查看详情”原地展开，长正文独立滚动，最大高度为 380px 与视口高度一半中的较小值；自动折行、保留缩进，边界限制惯性带动外层。读取大正文按块追加，失败保留内容并重试。

edit/write 不提供详情展开，不显示“Successfully replaced”等成功回执。对话仅保留文件路径、状态、可用的完整 diff 统计（绿色 +N、红色 −N，含无障碍名称）和“查看变更”；失败直接显示错误原因。统计在宿主根据完整 diff 计算，排除文件头，不使用截断预览估算。旧记录无统计时省略数字；纯 write 将完整写入正文计为新增行，显示 +N −0；结果提供实际 diff 时以 diff 统计为准。

“查看变更”和每轮文件清单共用当前对话内的右侧面板。默认精简差异保留所有增删行和前后各三行未修改代码，相邻上下文重叠时合并；保留原始行号、增删标记、词级高亮和自动换行。已取得的长上下文使用轻量行内折叠条，每次展开二十行，可展开此段全部或原地收起，收起恢复折叠入口焦点。紧凑工具栏提供上一处／下一处修改和展开全部上下文／收起未修改代码；修改处数量在读取结束前标注读取中。展开只补偿当次位置，不持续控制滚动。未知格式保留原始差异并提示，文件头、分块头及缺失换行说明不折叠，不虚构未取得的历史内容，也不以当前磁盘文件补齐历史。纯新增、纯删除保留所有真实变更；若只有写入正文则显示“新增内容”，不推测修改前版本。正文逐块串行加载直至末尾，面板独立滚动，不受工具正文高度上限限制。失败保留已读内容与偏移，提供就地重试；切换变更或会话使旧读取失效。宽窗口左右排列，窄窗口在同一主内容区域展示变更，关闭返回原对话，始终保留列表实例、阅读位置与草稿。打开将焦点移到关闭入口，Escape 或关闭按钮返回触发按钮，不打开弹窗。面板开关只进行一次布局锚点恢复，不持续补偿滚动。

对话使用普通文档流，不使用消息或工具行虚拟列表，不回收已加载节点。首次由宿主返回最近 50 条消息，接近顶部 200px 时自动加载更早记录；不足一屏时逐批补充，直到可滚动或历史耗尽。一次仅请求一页，按消息 ID 去重并检查游标前进；会话切换后忽略旧请求。顶部状态行预留空间，显示加载、历史起点或就地错误；失败暂停自动请求，仅提供“重试加载历史”。

历史页中的普通消息空预览在插入前读取。提交前记录当时首个可见消息及其屏幕位置，插入后恢复一次锚点；请求期间允许继续滚动，不使用请求开始时的旧位置。已挂载正文不参与缓存淘汰，避免阅读期间突然缩短。随着读取历史增多，DOM 和内存会增长；此方案不承诺任意数量消息均保持恒定内存。

普通消息仅在超过 64KiB 预览上限时提供完整正文入口。复制按钮复制当前显示文本，远程图片不自动请求，代码语言按需高亮。上滚立即停止底部跟随，向下实际到达底部（容忍 2px 取整误差）或点击“回到底部”恢复；手动到底后箭头自动消失，后续流式内容继续跟随。消息提交成功后自动滚到当前会话最底部并继续跟随回复，包含文字、图片、引导与后续消息；发送失败、空输入、本地内置命令和迟到的其他会话提交结果不触发跟随。确认扩展选项或提交扩展输入后恢复当前会话底部跟随，包含阅读计划时上翻后点击“执行计划”；取消和超时保留原阅读位置。操作区收起、进度卡片出现等布局变化不视为主动上翻；执行期间用户再次上翻仍立即停止跟随，新增内容不抢走阅读位置。点击滚动区空白不暂停跟随；箭头贴近正文区域底部，随输入器和扩展操作区高度变化保持位置。展开收起工具也停止跟随。只有处于跟随状态时，内容总高度变化才定位到底部；阅读期间不持续执行测量补偿。

回归验证覆盖切换会话后连续原生滚轮与逐帧受控上翻、历史插入期间继续滚动、短页补足、失败重试、重复请求、迟到会话结果、工具内部滚动及收起入口的几何命中。浏览器自动化不等同于 macOS、Windows、Linux 原生客户端与触控板惯性验证。

快捷键：Ctrl/Cmd+N 新对话，Ctrl/Cmd+K 搜索，Ctrl/Cmd+B 侧栏，Ctrl/Cmd+, 应用设置。设置在主内容区打开；其余现存弹层使用原生 dialog 约束焦点，Escape 关闭并恢复焦点。扩展交互按队列显示，取消/超时最多回应一次。Plan 等选择类请求使用紧凑的横向按钮，窄窗口自动换行；附加说明按需展开，选项内容独立滚动且高度不超过视口的 22%。所有扩展请求可就地“收起操作”，保留标题、待选择提示、展开与取消入口，不取消请求或清空输入。选项区内 Escape 收起并将焦点返回展开入口；展开恢复原输入，超时仍按原请求处理。选择值与请求 ID 原样返回 Pi，操作区变化不重新挂载正文，不主动抢焦点。
