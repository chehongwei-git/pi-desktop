# 交互

侧栏包含新对话、当前项目历史搜索、项目选择与最近项目、设置。历史按今天、昨天、最近 7 天、更早分组。搜索仅匹配当前项目名称/首条用户摘要，150ms 防抖。打开历史后才能重命名，所有写入交给 Pi。

未选择项目时输入禁用。选择目录后连接 Pi；空会话使用居中欢迎页，出现消息后输入固定在底部。Enter 发送，Shift+Enter 换行，IME 确认不发送。提交失败保留原草稿，不隐式重发。草稿在内存按项目/会话保存，退出不长期保存。

运行时输入仍可编辑；发送须明确选择引导当前任务（steer）或完成后发送（followUp）。停止先清队列，再 abort；清出的文本列为可恢复草稿。5 秒未停止时显示强制关闭入口。运行中切换需选择停止并切换、等待完成或取消；等待可取消。

用户消息靠右，助手按正文排版；思考与工具默认折叠。大正文按 64KiB 分块查看，复制按钮复制当前显示文本。远程图片不自动请求，代码语言按需高亮。靠近底部自动跟随，上滚关闭跟随，可点击回到底部。加载历史保留滚动锚点。

快捷键：Ctrl/Cmd+N 新对话，Ctrl/Cmd+K 搜索，Ctrl/Cmd+B 侧栏，Ctrl/Cmd+, 设置。弹层使用原生 dialog 约束焦点，Escape 关闭并恢复焦点。扩展交互按队列显示，取消/超时最多回应一次。
