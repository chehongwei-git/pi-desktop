# 交互

## 视觉布局与阅读层次

主界面使用系统字体优先的跨平台回退，代码采用独立等宽字体回退；正文与输入为 16px，常用导航和控件为 13–14px，辅助说明约为 12px。中文欢迎标题不使用负字距。侧栏宽度为 288px，窄于 900px 时沿用可收起的抽屉；正文与输入共享 820px 最大内容宽度。

当前会话标题合并到顶栏，与连接状态及会话菜单同处一行，长标题省略并通过 title 保留完整名称。新会话与已有会话的输入器使用相同的底部位置，项目入口位于输入框上方。欢迎区在剩余空间内居中，短窗口仅欢迎区独立滚动。出现消息后沿用底部输入与独立正文滚动，不重新挂载对话。

浅色与深色主题分别定义页面、侧栏、输入表面、悬停和选中颜色。会话选中使用独立底色，键盘焦点使用轮廓；模型和强度入口减轻边框，保留文本、图标、启用色及键盘行为。折叠工具使用轻量摘要，展开后显示边界和吸顶标题；正文采用独立堆叠上下文，工具标题只在正文内部置顶，不遮挡输入区向上展开的模型、思考强度等菜单；失败仍突出错误状态。设置和归档沿用相同字号与表面层次，继续在主内容区完成。

视觉回归使用浏览器截图与现有任务测试，覆盖明暗主题、宽窄窗口、缩放、运行中输入、工具展开及长对话阅读锚点。浏览器验证不等于三个平台的原生客户端验证，也不代表已通过 WCAG 2.2 AA 审核。

## 上下文使用率

输入区右下角显示 Pi `get_session_stats` 返回的上下文使用百分比与已用／上限 tokens，数字缩写与终端一致；超过 70% 使用警告色，超过 90% 使用错误色，并提供对应的无障碍说明。压缩后未知用量显示问号，展开后说明需等待下一次回答。未连接、会话加载及本地新对话草稿页隐藏指标，避免展示后台旧会话读数。

点击指标在原处向上展开明细，展示累计输入、输出、缓存读取与写入、会话累计缓存命中率、费用及消息数；不打开弹窗。展开聚焦面板，Tab 可进入刷新按钮，Escape 收起并恢复入口焦点，点击外部或焦点移出时收起。连接、切换、任务结束及压缩后刷新，展开时也刷新；同一会话并发查询合并，迟到的旧会话结果忽略。查询失败保留上次读数，不打断消息发送。明细支持就地刷新。

## 消息提示

消息提示统一使用主内容区内的提示卡，不打开窗口或模态框。对话页在右上方悬浮显示，不改变对话高度和阅读锚点；归档页在顶部使用独立的页内区域，避免遮挡筛选、恢复和返回入口。卡片使用中性背景，通过图标、标题和颜色共同区分普通消息、成功、错误和停止警告；同时出现时错误优先，归档反馈其次，普通消息最后。窄窗口下卡片宽度跟随主区，多条提示在限定高度内滚动，页面其余区域仍可操作。

普通消息和成功提示在 5 秒后自动收起，错误和归档反馈在 8 秒后自动收起；归档反馈显示期间可撤销，收起后仍可从归档页恢复。鼠标悬停或键盘焦点进入时暂停计时，移开后重新计时。归档保存期间暂停收起；停止警告、压缩进行中的状态保留至手动关闭或业务状态更新。重连、设置、撤销和强制关闭操作位于对应卡片内。长消息默认预览三行，可就地展开或收起详情。提示不抢焦点；键盘关闭卡片时尝试回到提示出现前的控件，错误通过 alert、普通反馈通过 status 播报，操作按钮位于播报区域之外。适配明暗主题和减少动画偏好。

## 应用设置

侧栏“设置”与 Ctrl/Cmd+, 在主内容区打开同一个设置页，保留已挂载的对话、草稿和阅读位置。页面分为“外观”“Pi 连接”“模型与服务商”“会话与存储”，切换分类保留未保存的输入。外观使用带预览的原生单选卡片选择跟随系统、浅色或深色，保存后应用；缩放显示当前比例并提示 Ctrl/Cmd 与 +、−、0 快捷键。

Pi 连接集中展示入口、运行时和额外 PATH，提供可选标记、默认行为说明和独立的路径浏览入口。“检测 Pi”使用当前表单配置，在页面内显示版本、路径或失败详情。会话目录说明默认位置与保存后的索引刷新；兼容性说明按需展开。

底部固定显示保存状态与保存入口，提交时禁用重复操作，保存失败保留全部输入并可重试。侧栏归档、设置及对话导航以当前可见页面为准，归档与设置不会同时选中。设置中可直接点击归档、新对话或历史会话切换，无需先返回对话；存在未保存更改时，返回、Escape 与侧栏导航统一在设置底部提供“继续编辑”“放弃并继续”，确认后执行原目标操作，不打开确认弹窗。进入设置聚焦标题，返回恢复触发控件焦点。窄窗口中分类导航变为横向，内容区独立滚动。连接配置在下次连接时生效。模型与 API Key 可在“模型与服务商”中配置，OAuth 登录仍由 Pi CLI 管理。

## 模型与服务商

模型设置与本机 Pi CLI 共享 agent 目录中的 models.json、auth.json 和 settings.json，遵循 PI_CODING_AGENT_DIR；页面展示实际目录。认证只返回来源和已配置状态，不显示原始凭据。认证方式目前只有 API Key，输入新密钥表示替换，留空保留已有认证；环境变量、免认证和订阅不提供新增选项，后续扩展订阅时再增加认证方式。替换 OAuth 需就地确认；已有命令型密钥与高级请求头原样保留，模型发现不执行密钥命令。

页面参考 @rotriz/pi-web-ui 1.6.0 的可搜索模型列表组织方式，使用自定义端点列表与详情区；窄窗口上下排列。只管理显式 API 地址的自定义端点，内置服务商及已有模型覆盖保留但不提供编辑入口。端点列表支持名称和地址搜索，添加在列表内展开，使用独立标识、必填完整 API 地址和明确协议，不再提供继承内置服务商入口。创建端点时显示名称默认填入端点标识，之后可独立修改。认证和 API Key 输入直接展示，全局默认值与共享配置说明按需展开。获取模型使用当前未保存的 API 地址、协议和认证，支持 OpenAI Chat Completions、Responses 及 Anthropic Messages。基础地址保留路径前缀，请求其下的 /models；需显式填写地址和协议才能发现模型。列表支持搜索、选择搜索结果和分批显示，勾选后加入草稿；失败不清空表单，可手动添加。取消等待会忽略迟到结果，宿主请求最多持续 30 秒。再次拉取不覆盖已配置参数；未返回的已有模型仅标记，不自动移除。模型目录可访问不代表生成请求或工具调用可用。

每个模型就地展开名称、上下文长度、最大输出、图片输入、思考能力。手动新增和远端发现的模型默认支持思考，模型默认强度为 off；读取已有自定义模型时，未声明的思考能力与默认强度也采用这两个默认值，保存时写入 Pi 共享配置。已有显式关闭或等级选择保留，仍可逐模型调整。其他能力留空或“继承默认”不写入覆盖，关闭图片或思考保存显式值。页面新增模型统一使用 models；已有 modelOverrides 原样保留，不在此页面展示或新增。数值必须为正整数且最大输出不能大于显式上下文长度。远端缺少图片、上下文或输出数据时继承 Pi 默认；当前界面不展示目录继承参数的有效数值。

思考映射支持 off/minimal/low/medium/high/xhigh/max，每项可继承、禁用（null）或填写服务端值。到 high 的缺省映射使用协议默认；xhigh、max 依赖显式或目录映射。配置模型默认等级与全局默认等级，新会话默认模型与当前会话选择分开；当前会话使用输入框底部的模型和思考控件。全局默认思考等级未配置时默认为 off。默认模型列表只列出自定义端点中的模型，既有 CLI 默认值仍保留并标明已有配置。

保存沿用设置页底部入口，模型草稿在切换分类时保留。成功清空新输入密钥并继续停留页面。空闲时仅刷新本地模型配置并重新应用当前模型；运行中保存并延后至 idle。失败明确区分保存失败与已保存但应用失败，可重试应用。默认启动设置需要后续新进程读取，必要时重新连接；共享默认值不强制覆盖项目选择；存在桌面项目统一偏好时，恢复会话采用该项目偏好。未连接时保存不启动 Pi。移除模型和服务商配置均就地确认；服务商移除可选清除凭据，保存前可撤销。保留的认证独立存放于 auth.json，后续保存不会因此在 models.json 中重建空服务商；保存时会清理旧版本遗留的空服务商对象。

外部修改触发版本冲突，保留草稿；重新读取需就地确认放弃草稿。共享配置损坏时不覆盖，需先修复文件。每个文件原子替换，多文件 IO 失败尝试逆序恢复；进程在保存期间被强杀仍可能留下部分写入及锁目录，需要检查共享配置。与 CLI 共用目录锁，不主动抢占锁。

## 侧栏操作与布局

项目和会话提供“更多操作”按钮，与右键共用重命名、归档菜单。菜单支持方向键、Home/End、Enter 和 Escape；主动关闭时恢复入口焦点，点击外部或窗口失焦时不抢焦点。重命名在原行内完成，Enter 保存、Escape 取消，输入法确认不提交；保存失败保留输入并就地显示可重试错误。结束编辑后恢复原对象焦点。归档保持原有撤销与恢复流程。

最近会话和每个项目的会话默认显示 20 条，可按每次 20 条继续加载，计数徽标仍显示完整数量。已归档与设置固定在侧栏底部，不随历史列表滚动。区块和项目展开状态、侧栏显示状态保存在当前应用的本地界面偏好中；存储不可用时使用页内提示。搜索临时展开不写入普通浏览偏好。

会话采用整行悬停与焦点反馈，已置顶图钉持续突出；鼠标环境下次要按钮弱化，但位置始终保留，键盘聚焦和触控环境正常显示。当前项目通过底色、文字及侧边标记共同表达。打开侧栏聚焦搜索入口，收起后返回展开按钮；Escape 优先清除搜索，窄窗口无搜索时收起侧栏。取消置顶导致当前行消失时，焦点移到相邻会话或区块标题。

## 归档管理

归档是唯一的历史收纳入口，不再提供回收站或移入回收站操作。旧版 deleted 记录在归档中兼容展示，下次成功保存归档元数据时统一为 archived；恢复和撤销均保留原始文件。

侧栏“已归档”在主内容区打开管理视图，不使用模态弹窗。进入时保留已挂载的对话、草稿和阅读位置，返回对话不重新加载历史。归档按“全部／项目／会话”分类并显示数量，按所属项目分组，支持项目筛选与名称、项目名、路径组合搜索。无法从索引确定项目的旧会话归入“未识别项目”。首次显示 50 项，可继续加载；筛选后重置展示数量，区分空列表与无匹配结果。

归档直接执行并提供最近一步的撤销；恢复也支持撤销。保存失败保留原状态并允许重试。归档当前会话不会中断任务或清空草稿。归档项目一并隐藏其会话，但不改变单个会话的状态；恢复项目不会恢复单独归档的会话。恢复会话时如所属项目仍归档，则提示需恢复项目。

进入管理页聚焦标题，恢复一项后聚焦相邻恢复按钮，列表为空时回到标题，返回时恢复入口焦点。

侧栏依次包含“置顶”“工作项目”“最近”，三块均可独立展开或收起。启动时自动发现 Pi 会话目录中的全部工作区，并补充最近打开的项目；“工作项目”默认展示前 5 个，可点击“显示全部”查看其余项目，收起区块后再次展开恢复前 5 个。工作区按会话 header.cwd 分组，默认按规范化路径排序；可拖拽项目标题调整顺序，落点显示上方或下方插入线，也可聚焦标题后使用 Alt+↑/↓。项目顺序保存到配置中，重启、搜索、切换会话和刷新索引都不会按活跃时间重排项目。点击项目展开或收起其中会话；项目内会话和“最近”都按最后发送用户消息的时间倒序排列，发送成功后立即提前；打开、重命名、助手回复或文件更新时间变化均不改变顺序。没有用户消息时以创建时间和路径作为稳定排序依据。“最近”跨项目展示会话，并标明所属项目。会话旁的图钉可置顶或取消置顶，偏好保存在本地配置中，重启后保留。侧栏历史列表为滚动条预留稳定间距，置顶按钮与滚动条之间保持可点击的安全距离。区块标题使用舒展的行高与分组间距，统计数字以浅色徽标紧随标题，右侧操作按钮独立留白；项目行统一箭头尺寸、行高和计数徽标，长项目名省略显示，计数与新建按钮之间保留间距。

应用启动时在最近项目（没有则使用系统用户目录）预先连接一个 Pi 实例；展开区块或项目不创建额外进程。点击已有会话直接通过同一 Pi 的 switch_session 恢复历史，跨项目时由 Pi 根据会话 header.cwd 重建工具、配置和扩展。项目旁的 + 可直接在该项目新建会话；在其他项目新建仍需重新连接该目录。搜索在所有项目的会话名称、首条用户摘要、项目显示名称和工作目录中匹配，自动展开匹配项目，搜索结果不受前 5 个项目限制。搜索框提供清除入口与会话结果数量；没有结果的区块隐藏，全部无匹配时统一显示一条说明。搜索期间可独立折叠区块和项目，清空搜索后恢复原浏览布局。窗口重新获得焦点时刷新索引，设置中修改会话目录后立即刷新。侧栏重命名统一修改桌面显示别名，不修改会话文件或工作目录；顶部会话菜单的重命名仍交给 Pi。会话名称固定显示在对话顶栏；切换时立即显示目标会话名称，正文区域仅显示加载转圈，覆盖跨项目连接与历史读取过程。加载完成后显示目标消息，期间禁用发送和重复切换；被扩展取消或切换失败时结束加载状态。

新对话尚未首次发送时只是本地草稿页，后台保留原会话。在草稿页显式选择的模型会在首次发送创建真实会话后再次应用，避免创建时恢复默认模型导致选择失效；模型应用失败保留首条消息并停止发送，重试不重复创建会话。此时点击后台仍在使用的会话，直接返回其正文并恢复原草稿，保留工具展开状态；新对话草稿独立保存，再次进入时恢复。返回原会话不触发 Pi 会话切换或扩展切换钩子；点击其他历史会话仍按正常恢复流程处理。

连接前输入禁用。点击“新对话”（或 Ctrl/Cmd+N）时，未选项目则直接在系统用户目录启动 Pi，已选项目则在当前项目新建会话。新对话在输入框上方显示文件夹按钮，展开后可搜索并选择全部已知项目，不受侧栏前 5 个项目限制；底部“新建项目”通过目录选择器指定工作目录，“不在此项目工作”切换到系统用户目录。展开和搜索不启动 Pi，切换工作目录保留当前草稿。项目选择面板使用标题与说明、名称/路径搜索、带数量的项目列表及独立底部操作区。项目名称与完整路径分两行显示，当前项目通过底色、“当前”文字及勾选共同标记；用户目录选项也显示选中状态。无项目与搜索无结果分别提供就地说明，列表独立滚动，适配明暗主题与窄窗口。项目面板在按钮上方向上展开，不参与页面排版，展开与收起均保持输入框位置不变；欢迎区独立滚动，避免裁切项目面板。打开后聚焦搜索；方向键在搜索、项目和底部操作间移动，搜索框 Enter 选择首个匹配项目（IME 确认除外），按钮 Enter/Space 执行，Escape 收起并恢复入口焦点，Tab 移出或点击外部关闭。鼠标按下菜单按钮时显式将焦点移到按钮，避免 macOS WebView 在 click 前因搜索框失焦而提前卸载面板。选择当前项目只收起面板，不重复连接。仍可通过目录选择器指定项目后连接 Pi。空会话使用居中欢迎区，输入框始终保持在底部。Enter 发送，Shift+Enter 换行，IME 确认不发送。提交失败保留原草稿，不隐式重发。草稿在内存按项目/会话保存，退出不长期保存。

模型和思考强度位于输入框底部左侧，以图标、文字和强度启用色区分，发送按钮位于右侧。模型和强度按工作项目统一：通过下拉控件或 /model、/thinking 修改后，将两项作为一组保存到桌面项目偏好；同目录的历史会话、新会话及首次发送前均应用这组值，重启后保留，不同项目独立。Windows 路径大小写与分隔符别名视为同一项目。未显式设置过的项目沿用原有会话或 Pi 默认值；首次修改后统一。历史消息不改写，未打开会话在恢复时应用。项目模型不可用或应用失败时就地提示，发送前失败保留草稿且不发送；保存失败明确区分当前会话已生效与项目偏好未落盘。跨项目草稿入口显示目标项目已保存的模型与强度。强度 off 也始终可见；只有 off 可用时禁用强度选择。模型使用输入区内向上展开的搜索面板，按服务商分组，服务商及组内模型按名称排序，保留当前会话中未在目录返回的模型；模型名称与 ID 分行显示，当前项通过底色、文字和勾选标记。入口同时显示模型名称和服务商。搜索匹配名称、ID 与服务商；初次展示最多 80 项，可继续加载，分组数量表示已展示项数。打开聚焦搜索，方向键在搜索及选项之间移动，按钮支持 Home/End，搜索框 Enter 选择首个结果（IME 确认除外），Escape 关闭并恢复入口焦点，Tab 移出或点击外部关闭。切换模型后重新应用当前思考强度；若新模型不支持原等级，则显示就地通知并采用 Pi 返回的有效等级，强度恢复请求失败时明确提示模型已切换并保留草稿。草稿页首次发送重建会话后也保留所选模型及思考强度。思考强度使用输入区内向上展开的菜单，显示中文等级、原始等级标识、用途说明及当前选中标记；入口以阶梯图形和文字表达当前强度。Enter/Space 或方向键打开，方向键与 Home/End 移动，Enter/Space 选择，Escape 关闭并恢复入口焦点，Tab 移出、点击外部或窗口失焦时关闭且不抢焦点；仅展示当前模型支持的等级。模型或强度切换期间暂停发送和重复切换，保留可编辑草稿；失败在控件附近提示并恢复 Pi 确认的选项。运行中、会话加载或未连接时禁用切换。窄窗口控件与发送区换行，适配明暗主题。

运行时输入仍可编辑；Enter 或“发送引导”直接提交 steer，在下一个可处理节点生效；“完成后发送”提交 followUp，排在当前任务之后。发送与“停止任务”是独立按钮，停止按钮使用实色圆形背景；提交中避免重复发送但仍可停止。引导与后续消息提交时立即显示在对话中，标明正在提交/等待处理，Pi 返回正式用户消息时原位替换，避免重复。提交成功反馈提示，失败移除占位并保留草稿。停止先清队列，再 abort；清出的文本列为可恢复草稿。5 秒未停止时显示强制关闭入口。运行中切换需选择停止并切换、等待完成或取消；等待可取消。

用户消息靠右，助手按正文排版；思考默认折叠。工具步骤显示工具名、完整命令或文件路径及状态，命令自动换行。输出、参数、详细错误、截断说明与完整输出路径默认隐藏，不展示任何正文预览。点击标题“查看详情”原地展开，长正文独立滚动，最大高度为 380px 与视口高度一半中的较小值；自动折行、保留缩进，边界限制惯性带动外层。读取大正文按块追加，失败保留内容并重试。

edit/write 不提供详情展开，不显示“Successfully replaced”等成功回执。对话仅保留文件路径、状态、可用的完整 diff 统计（绿色 +N、红色 −N，含无障碍名称）和“查看变更”；失败直接显示错误原因。统计在宿主根据完整 diff 计算，排除文件头，不使用截断预览估算。旧记录无统计时省略数字；纯 write 将完整写入正文计为新增行，显示 +N −0；结果提供实际 diff 时以 diff 统计为准。

“查看变更”打开当前对话内的右侧面板，显示该次调用完整差异，保留原始行号、增删标记、词级高亮和自动换行；若只有写入正文则显示“新增内容”。正文逐块串行加载直至末尾，面板独立滚动，不受工具正文高度上限限制。失败保留已读内容与偏移，提供就地重试；切换变更或会话使旧读取失效。宽窗口左右排列，窄窗口在同一主内容区域展示变更，关闭返回原对话，始终保留列表实例、阅读位置与草稿。打开将焦点移到关闭入口，Escape 或关闭按钮返回触发按钮，不打开弹窗。面板开关只进行一次布局锚点恢复，不持续补偿滚动。

对话使用普通文档流，不使用消息或工具行虚拟列表，不回收已加载节点。首次由宿主返回最近 50 条消息，接近顶部 200px 时自动加载更早记录；不足一屏时逐批补充，直到可滚动或历史耗尽。一次仅请求一页，按消息 ID 去重并检查游标前进；会话切换后忽略旧请求。顶部状态行预留空间，显示加载、历史起点或就地错误；失败暂停自动请求，仅提供“重试加载历史”。

历史页中的普通消息空预览在插入前读取。提交前记录当时首个可见消息及其屏幕位置，插入后恢复一次锚点；请求期间允许继续滚动，不使用请求开始时的旧位置。已挂载正文不参与缓存淘汰，避免阅读期间突然缩短。随着读取历史增多，DOM 和内存会增长；此方案不承诺任意数量消息均保持恒定内存。

普通消息仅在超过 64KiB 预览上限时提供完整正文入口。复制按钮复制当前显示文本，远程图片不自动请求，代码语言按需高亮。上滚立即停止底部跟随，向下实际到达底部或点击“回到底部”恢复；展开收起工具也停止跟随。只有处于跟随状态时，内容总高度变化才定位到底部；阅读期间不持续执行测量补偿。

回归验证覆盖切换会话后连续原生滚轮与逐帧受控上翻、历史插入期间继续滚动、短页补足、失败重试、重复请求、迟到会话结果、工具内部滚动及收起入口的几何命中。浏览器自动化不等同于 macOS、Windows、Linux 原生客户端与触控板惯性验证。

快捷键：Ctrl/Cmd+N 新对话，Ctrl/Cmd+K 搜索，Ctrl/Cmd+B 侧栏，Ctrl/Cmd+, 应用设置。设置在主内容区打开；其余现存弹层使用原生 dialog 约束焦点，Escape 关闭并恢复焦点。扩展交互按队列显示，取消/超时最多回应一次。
